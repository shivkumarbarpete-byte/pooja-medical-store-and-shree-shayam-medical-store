
# Pooja Medical Store & Shree Shyam Medical Store

A simple and responsive website for **Pooja Medical Store** and **Shree Shyam Medical Store**, designed to provide essential information about the stores and make it easy for customers to connect with them.

## 🌐 Live Website

**[Visit Live Website](https://pooja-medical-store.vercel.app/)**

## 📌 About the Project

This project is a frontend website created for two medical stores:

* **Pooja Medical Store**
* **Shree Shyam Medical Store**

The website provides a clean and user-friendly interface for customers to view store information and access important contact details.

## ✨ Features

* 🏥 Medical store information
* 📱 Responsive design
* 📍 Store/contact information
* 🖼️ Store images
* 💻 Simple and user-friendly interface
* 🚀 Deployed on Vercel

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Vercel

## 🚀 Deployment

The website is deployed using **Vercel** and connected with the GitHub repository for easy updates.
